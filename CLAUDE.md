## Project

A web-based network topology diagram tool. Tech stack is React + TypeScript + Vite. A diagramming library (React Flow, mxGraph, or vis.js) has not yet been selected.

## Commands

```bash
npm install         # install dependencies
npm run dev         # start dev server (Vite HMR)
npm run build       # tsc type-check + Vite production build → dist/
npm run lint        # oxlint
npm run preview     # preview production build locally
```
